# SC-10: 控制台页导航栏交互

**优先级**: P2
**质量维度**: 功能适用性、易用性

## 前置条件

1. 用户已成功登录系统
2. 用户处于控制台页面
3. 顶部导航菜单项可见且可点击

## 操作步骤

### 步骤 1: 验证导航菜单项存在
1. 在控制台页面找到顶部导航栏
2. **预期**: 导航栏中存在以下菜单项：
   - "备案"
   - "资源"
   - "费用"（或"费用与成本"）
   - "企业"（如有）
   - "工具"（如有）
   - "工单"（如有）

### 步骤 2: 点击各菜单项并验证跳转
1. 点击"备案"菜单项
   **预期**: URL 变化，页面跳转至备案子页面
2. 返回控制台页面
3. 点击"资源"菜单项
   **预期**: URL 变化，页面跳转资源子页面
4. 返回控制台页面
5. 点击"费用"菜单项
   **预期**: URL 变化，页面跳转至费用子页面

### 步骤 3: 验证子页面内容
1. 对每个子页面，检查内容是否正确加载
2. **预期**: 子页面内容与其菜单项名称匹配
3. **预期**: 页面无加载错误或 404 信息
4. **预期**: 可正常返回控制台页面

## 预期结果

- 每个导航菜单项点击后正确跳转至对应子页面
- 子页面内容正确渲染
- 导航交互流畅，无障碍

## 通过标准

- 所有导航菜单项均可点击
- 点击后 URL 变化匹配预期子页面路径
- 子页面内容正确加载
- 无 404 或加载错误页面

## 质量维度映射

- **功能适用性**: 导航跳转逻辑正确
- **易用性**: 导航交互直观，用户可流畅访问各个功能模块
