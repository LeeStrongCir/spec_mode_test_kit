# SC-09: 控制台页顶部搜索功能

**优先级**: P1
**质量维度**: 功能适用性、易用性

## 前置条件

1. 用户已成功登录系统
2. 用户处于控制台页面
3. 顶部搜索栏可见且可交互

## 操作步骤

### 步骤 1: 打开控制台页面
1. 登录系统并进入控制台页面
2. 确认页面顶部搜索栏存在且可聚焦

### 步骤 2: 执行搜索
1. 点击顶部搜索栏输入框
2. 输入服务关键词（如"ECS"、"VPC"、"对象存储"）
3. 按回车键或点击搜索按钮
4. **预期**: 搜索请求发送至搜索服务端点
5. **预期**: 页面跳转至搜索结果页面或下拉搜索结果面板展开

### 步骤 3: 验证搜索结果
1. 检查搜索结果区域
2. **预期**: 搜索结果页面正确加载
3. **预期**: 搜索结果中包含相关服务/资源
4. **预期**: 关键词在搜索结果中高亮显示
5. 搜索结果页面可交互（可点击结果项进入详情）

## 预期结果

- 搜索功能正常响应用户输入
- 搜索结果准确匹配关键词
- 搜索结果页面正确加载并可交互

## 通过标准

- 搜索请求成功发出并收到响应（非 4xx/5xx 错误）
- 搜索结果页面正确加载
- 关键词在结果中高亮匹配

## 质量维度映射

- **功能适用性**: 搜索功能正确处理用户请求
- **可用性**: 搜索交互流畅，结果展示准确
