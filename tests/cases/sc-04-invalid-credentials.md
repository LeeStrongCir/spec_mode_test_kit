# SC-04: 无效凭证登录拒绝

**优先级**: P1
**质量维度**: 功能适用性、安全性

## 前置条件

1. 用户处于登录页面
2. 系统中存在有效的管理员账号 `admin`

## 操作步骤

### 测试组 1: 用户名错误
1. 输入不存在的用户名 `wronguser`
2. 输入正确密码 `admin@123`
3. 点击"登录"
4. **预期**: HTTP 状态码为 401
5. **预期**: 页面显示"用户名或密码错误"（或等价错误提示）
6. **预期**: 页面停留在登录页面，不跳转

### 测试组 2: 密码错误
1. 输入正确用户名 `admin`
2. 输入错误密码 `wrongpass`
3. 点击"登录"
4. **预期**: HTTP 状态码为 401
5. **预期**: 页面显示"用户名或密码错误"
6. **预期**: 页面停留在登录页面

### 测试组 3: 两者皆错误
1. 输入错误用户名 `wronguser`
2. 输入错误密码 `wrongpass`
3. 点击"登录"
4. **预期**: HTTP 状态码为 401
5. **预期**: 页面停留，显示错误提示

## 预期结果

- 所有无效凭证组合均返回 401  Unauthorized 响应
- 用户停留在登录页面
- 显示用户友好的错误提示信息
- 页面 URL 不发生改变

## 通过标准

- 无效凭证认证请求返回 401 状态码
- 页面显示明确的错误提示
- 不发生页面跳转

## 质量维度映射

- **功能适用性**: 认证拦截逻辑正确
- **安全性**: 不通过错误信息泄露是否存在该用户名（统一错误提示）
