# SC-07: 默认密码首次强制修改

**优先级**: P2
**质量维度**: 功能适用性、安全性

## 前置条件

1. 系统已完成初始化
2. 管理员账号 `admin` / `admin@123` 已创建，`firstLogin` 标志为 `true`
3. 从未使用 admin 账号登录过（或刚重置密码后）

## 操作步骤

### 步骤 1: 首次登录
1. 在登录页面输入用户名 `admin`
2. 输入初始密码 `admin@123`
3. 点击"登录"按钮

### 步骤 2: 验证密码修改提示
1. 认证成功后
2. **预期**: 页面弹出"首次登录，请修改默认密码"提示（弹窗或跳转至密码修改页面）
3. **预期**: 用户无法直接进入控制台页面，必须完成密码修改

### 步骤 3: 执行密码修改
1. 输入旧密码 `admin@123`
2. 输入新密码（符合密码策略：含大小写字母、数字、特殊字符，≥8 位）
3. 确认新密码
4. 点击"确认修改"

### 步骤 4: 验证修改后的状态
1. **预期**: 密码修改成功提示
2. **预期**: `firstLogin` 标志更新为 `false`
3. **预期**: 自动跳转至控制台页面

## 预期结果

- 首次登录后强制弹出密码修改流程
- 新密码符合密码策略后才允许提交
- 修改后用户可正常使用系统

## 通过标准

- 首次登录触发密码修改弹窗/页面
- 用户不修改密码无法访问控制台
- 密码修改成功后 `firstLogin` 标志更新
- 新密码复杂度校验生效

## 质量维度映射

- **功能适用性**: 首次登录强制改密逻辑正确
- **安全性**: 弱口令 `admin@123` 被强制替换，降低安全风险
