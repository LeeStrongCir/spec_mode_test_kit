# SC-06: 品牌文案全量替换验证

**优先级**: P0
**质量维度**: 功能适用性

## 前置条件

1. 系统已完成部署，所有页面可访问
2. 浏览器已打开任一系统页面

## 操作步骤

### 步骤 1: 自动化全量源码搜索
1. 在项目源代码目录 `src/`（或 `public/`、`templates/` 等前端代码目录）上执行全局搜索：
   `grep -r "华为云" src/ public/ templates/`
2. 检查 `src/`（或 `public/`、`templates/`）
3. **预期**: 搜索结果为零条
4. **预期**: 不存在"华为云"残存文案

### 步骤 2: 人工对照清单逐一检查

| UI 区域 | 预期替换后内容 | 验证结果 |
|---------|----------------|----------|
| Logo 区域 | 显示"Lee云"品牌 Logo 和文字，非"华为云" | □ 通过 |
| 页面标题（`<title>`） | 标题中包含"Lee云"（如"控制台｜Lee云 \| 华北-北京四"） | □ 通过 |
| 顶部导航栏 | 导航链接和菜单项显示"Lee云" | □ 通过 |
| 搜索栏提示文案 | 提示文字含"搜索Lee云服务"或等价 | □ 通过 |
| 页脚版权信息 | 显示"© Lee云"或等价 | □ 通过 |
| 帮助/文档入口 | 链接文字为"Lee云文档"、"Lee云社区" | □ 通过 |
| 欢迎文案 | 显示"欢迎来到Lee云"或等价 | □ 通过 |

### 步骤 3: 检查隐藏元数据
1. 查看页面 HTML 源码（F12 开发者工具）
2. 搜索 `<meta>` 标签中的 `description`、`keywords` 等属性
3. **预期**: 不含"华为云"字样
4. 检查 `favicon` 图标文件命名和路径中不含"华为云"

### 步骤 4: "Lee云"正向验证
1. 在上述 7 个 UI 区域中，逐一确认"Lee云"正确显示
2. **预期**: 每个区域均正确显示"Lee云"品牌文案

## 预期结果

- 全系统（前端代码 + 页面源码 + 元数据）中"华为云"出现次数为 0
- 原"华为云"出现位置均正确替换为"Lee云"
- 品牌一致性贯穿所有页面

## 通过标准

- `grep -r "华为云"` 在所有前端代码文件中的搜索结果为零条
- 7 个 UI 区域对照清单全部通过
- 隐藏元数据（meta 标签、favicon 等）无"华为云"残存
- 所有位置均正确显示"Lee云"

## 质量维度映射

- **功能适用性**: 品牌替换 100% 覆盖，无遗漏
