# SC-01: 控制台页面渲染展示

**优先级**: P0
**质量维度**: 功能适用性、易用性

## 前置条件

1. 系统已完成初始化
2. 管理员账号 `admin` / `admin@123` 已创建
3. 用户已成功登录系统
4. 浏览器已打开

## 操作步骤

### 步骤 1: 登录后进入控制台页面
1. 在登录页面输入用户名 `admin`
2. 输入密码 `admin@123`
3. 点击"登录"按钮
4. **预期**: 页面跳转至控制台页面（URL 变为 `/console` 或等价路径）

### 步骤 2: 验证 TopBar 顶部栏存在
1. 检查页面顶部是否存在 TopBar 区域
2. 检查 TopBar 中是否包含以下元素：
   - **预期**: Logo 区域（显示"Lee云"品牌标识）
   - **预期**: 全局搜索栏（带搜索图标和提示文字）
   - **预期**: 导航菜单项（备案、资源、费用、企业、工具、工单）
   - **预期**: 用户头像/菜单区域

### 步骤 3: 验证 Tabs 选项卡存在
1. 检查页面顶部选项卡区域是否存在
2. 检查是否包含以下 Tab 项：
   - **预期**: "总览"（默认选中）
   - **预期**: "安全监控"
   - **预期**: "运维监控"
   - **预期**: "费用与成本"

### 步骤 4: 验证概览面板卡片存在
1. 检查概览区域是否包含以下卡片：
   - **预期**: "安全威胁告警"卡片（或类似安全状态卡片）
   - **预期**: "待续费"卡片
   - **预期**: "配置提醒"卡片
   - **预期**: "优化顾问"卡片
   - **预期**: "可用额度"卡片

### 步骤 5: 验证服务视图存在
1. 检查服务视图区域是否存在
2. 验证是否包含区域选择器（如"全部区域"、"华北-北京四"等）
3. 验证是否包含 VPC 资源项列表

### 步骤 6: 验证底部面板存在
1. 检查底部面板区域是否存在
2. 确认以下面板的存在：
   - **预期**: "安全监控"面板
   - **预期**: "费用与成本"面板

### 步骤 7: 验证 Footer 页脚信息
1. **预期**: 页脚包含"欢迎来到Lee云"欢迎文案
2. **预期**: 页脚包含"帮助中心"链接

## 预期结果

- 所有关键组件均正确渲染在页面中
- 页面布局与设计稿 `screanshots/华为云控制台.png` 结构一致（不验证像素级样式）
- 所有组件均可交互（按钮可点击、输入框可聚焦）
- 页面加载完成，无控制台 JavaScript 错误

- DOM 中存在所有关键组件的 HTML 元素
- 页面无加载错误
