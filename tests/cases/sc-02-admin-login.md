# SC-02: 管理员初始凭证登录

**优先级**: P0
**质量维度**: 功能适用性、安全性

## 前置条件

1. 系统已完成初始化
2. 管理员账号 `admin` / `admin@123` 已存在系统中
3. 用户处于登录页面
4. 浏览器网络连接正常

## 操作步骤

### 步骤 1: 输入正确管理员凭证
1. 在登录页面的用户名输入框中输入 `admin`
2. 在密码输入框中输入 `admin@123`
3. 点击"登录"按钮
4. **预期**: 系统验证凭证，返回认证成功
5. **预期**: HTTP 状态码为 200（或等价成功响应）
6. **预期**: 响应中包含认证 Token

### 步骤 2: 验证登录结果
1. 认证成功后，用户状态变更为"已登录"
2. 页面发生跳转至控制台页面
3. **预期**: 用户名 `admin` 显示在页面右上角或用户菜单中
4. **预期**: 用户角色显示为"管理员"

## 预期结果

- 凭证 `admin/admin@123` 被系统接受
- 认证成功，返回有效认证 Token
- 用户状态从"未登录"变更为"已登录"
- 页面自动跳转至控制台页面

## 通过标准

- 认证请求返回 200 状态码
- 响应体包含有效 Token
- 页面跳转至 `/console` 路径

## 质量维度映射

- **功能适用性**: 认证逻辑正确，管理员凭证被接受
- **安全性**: 使用弱口令 `admin@123`，系统应在首次登录后强制修改密码（风险记录）
