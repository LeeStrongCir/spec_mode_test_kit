# SC-01: 搜索导航至LECS主机列表页

**优先级**: P1
**质量维度**: 功能适用性、易用性

## 前置条件

1. 系统已完成初始化
2. 管理员账号 `admin` / `admin@123` 已创建
3. 用户已成功登录 Lee 云平台控制台
4. 浏览器已打开且页面加载完成
5. 控制台顶部搜索栏功能可用

---

## TC-001: 验证搜索"LECS"关键词匹配与高亮显示

**优先级**: P1
**来源**: `specs/001-lecs-host-management/spec.md` - 用户故事1, TC-001

### 操作步骤

### 步骤 1: 定位控制台顶部搜索栏
1. 在控制台页面找到顶部 TopBar 区域的全局搜索栏
2. **预期**: 搜索栏可见，带有搜索图标和提示文字

### 步骤 2: 输入"LECS"关键词
1. 点击搜索栏输入框，使其获得焦点
2. 在搜索栏中逐个字符输入 `LECS`
3. **预期**: 输入过程中下拉搜索结果面板自动展开

### 步骤 3: 验证搜索结果中出现"LECS主机"条目
1. 观察下拉搜索结果面板
2. **预期**: 下拉列表中出现"LECS主机"条目（或类似名称的导航项）
3. **预期**: "LECS主机"条目可被正常渲染，文字清晰可读

### 步骤 4: 验证关键词高亮显示
1. 仔细观察"LECS主机"条目中的文字
2. **预期**: "LECS"四个字母在结果条目中以高亮样式显示（如加粗、变色或背景高亮）
3. **预期**: 高亮部分与用户输入的"LECS"完全对应

## 预期结果

- 在控制台顶部搜索栏输入"LECS"后，下拉搜索结果中正确出现"LECS主机"条目
- "LECS"关键词在搜索结果条目中清晰高亮显示
- 下拉面板渲染正常，无错位、重叠或截断
- 页面无 JavaScript 控制台错误

## 通过标准

- DOM 中存在包含"LECS主机"文本的下拉搜索结果项
- "LECS"关键词在搜索结果中带有区别于普通文本的视觉高亮样式
- 整个过程无页面报错或控制台异常

## TC-003: 验证点击搜索结果跳转至LECS主机列表页

**优先级**: P1
**来源**: `specs/001-lecs-host-management/spec.md` - 用户故事1, TC-003

### 操作步骤

### 步骤 1: 执行搜索操作
1. 在控制台顶部搜索栏中输入 `LECS` 或 `云服`
2. **预期**: 下拉搜索结果面板展开，其中包含"LECS主机"条目

### 步骤 2: 点击搜索结果中的"LECS主机"条目
1. 鼠标移动到"LECS主机"条目上，确认该条目可被点击（如鼠标变为手型指针）
2. 点击"LECS主机"条目
3. **预期**: 下拉搜索结果面板收起

### 步骤 3: 验证 URL 跳转
1. 观察浏览器地址栏的 URL 变化
2. **预期**: URL 跳转至 `/console/lecs-hosts/list`（或等价完整路径，如 `https://<domain>/console/lecs-hosts/list`）
3. **预期**: 浏览器历史记录中新增一条记录（可点击后退按钮返回控制台）

### 步骤 4: 验证列表页正常加载
1. 等待页面加载完成
2. **预期**: 页面展示 LECS 主机列表页的布局结构
3. **预期**: 页面无错误提示（如 404、500 或"页面不存在"等提示）
4. **预期**: 浏览器开发者工具 Console 中无 JavaScript 报错信息

### 步骤 5: 验证列表页基本元素存在
1. 检查页面标题或面包屑导航
2. **预期**: 页面标题或面包屑中包含"LECS主机"或"主机列表"字样
3. 检查页面中是否存在主机数据表格区域
4. **预期**: 表格区域可见（即使无数据也应显示"暂无数据"提示）
5. **预期**: 页面右上角或顶部存在"创建LECS主机"按钮

## 预期结果

- 点击搜索结果中的"LECS主机"条目后，浏览器正确导航至 `/console/lecs-hosts/list`
- LECS 主机列表页正常加载，页面结构完整
- 页面无任何错误提示或告警信息
- 浏览器 Console 中无 JavaScript 异常

## 通过标准

- 导航后当前 URL 路径为 `/console/lecs-hosts/list`
- 页面 DOM 中存在 LECS 主机列表页的关键元素（标题、表格区域、创建按钮等）
- 页面无 HTTP 404/500 错误，无前端报错
- 浏览器 Console 无 JavaScript 错误输出
