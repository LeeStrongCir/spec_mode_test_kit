# SC-04: 主机生命周期控制（关机/启动）

**优先级**: P1
**质量维度**: 功能适用性、可靠性

## 前置条件

1. 系统已完成初始化
2. 管理员账号 `admin` / `admin@123` 已创建
3. 用户已成功登录系统并导航至 `/console/lecs-hosts/list`
4. 系统中存在处于以下状态的主机：
   - "正常"（normal）状态的主机至少 1 台
   - "已关机"（stopped）状态的主机至少 1 台
   - "创建失败"（failed）状态的主机至少 1 台
5. 后端 API 服务正常运行

## 操作步骤

### TC-040: 验证关机操作完整状态流转

- **优先级**: P1
- **追溯**: SC-04/TC-040

| 步骤 | 操作 | 预期结果 |
|------|------|----------|
| 1 | 在列表页找到状态为"正常"（normal）的主机行 | 该行操作列中"关机"按钮可点击，"启动"和"删除"按钮置灰 |
| 2 | 点击该主机的"关机"按钮 | "关机"按钮立即置灰不可点击；主机状态标签从"正常"（绿色）变为"关机中"（黄色/橙色过渡态颜色）；此时该行"关机"、"启动"、"删除"三个按钮全部置灰 |
| 3 | 等待约 10 秒（观察状态过渡） | 主机状态标签从"关机中"变为"已关机"（灰色）；"启动"按钮恢复可点击状态；"关机"和"删除"按钮恢复置灰（删除按钮对已关机状态应为可点击，需根据操作矩阵确认） |
| 4 | 刷新页面验证最终状态 | 主机仍显示为"已关机"状态，操作按钮状态与步骤 3 一致，无异常 |

### TC-041: 验证启动操作完整状态流转

- **优先级**: P1
- **追溯**: SC-04/TC-041

| 步骤 | 操作 | 预期结果 |
|------|------|----------|
| 1 | 在列表页找到状态为"已关机"（stopped）的主机行 | 该行操作列中"启动"按钮可点击（删除按钮也可点击），"关机"按钮置灰 |
| 2 | 点击该主机的"启动"按钮 | "启动"按钮立即置灰不可点击；主机状态标签从"已关机"（灰色）变为"启动中"（蓝色过渡态颜色）；此时该行"关机"、"启动"、"删除"三个按钮全部置灰 |
| 3 | 等待约 10 秒（观察状态过渡） | 主机状态标签从"启动中"变为"正常"（绿色）；"关机"按钮恢复可点击状态；"启动"和"删除"按钮恢复置灰 |
| 4 | 刷新页面验证最终状态 | 主机仍显示为"正常"状态，操作按钮状态与步骤 3 一致，无异常 |

### TC-042: 验证"创建失败"状态主机的启动

- **优先级**: P1
- **追溯**: SC-04/TC-042

| 步骤 | 操作 | 预期结果 |
|------|------|----------|
| 1 | 在列表页找到状态为"创建失败"（failed）的主机行 | 该行操作列中"启动"按钮可点击（删除按钮也可点击），"关机"按钮置灰 |
| 2 | 点击该主机的"启动"按钮 | "启动"按钮立即置灰不可点击；主机状态标签从"创建失败"（红色）变为"启动中"（蓝色过渡态颜色）；此时该行"关机"、"启动"、"删除"三个按钮全部置灰 |
| 3 | 等待约 10 秒（观察状态过渡） | 主机状态标签从"启动中"变为"正常"（绿色）；"关机"按钮恢复可点击状态；"启动"和"删除"按钮恢复置灰 |
| 4 | 刷新页面验证最终状态 | 主机仍显示为"正常"状态，操作按钮状态与步骤 3 一致，无异常 |

### TC-043: 验证过渡态防重复操作

- **优先级**: P1
- **追溯**: SC-04/TC-043

| 步骤 | 操作 | 预期结果 |
|------|------|----------|
| 1 | 触发一台"正常"主机的关机操作，等待其进入"关机中"状态（参考 TC-040 步骤 2） | 主机状态显示为"关机中"，操作列"关机"、"启动"、"删除"三个按钮全部置灰不可点击；尝试点击任一按钮均无反应（前端拦截） |
| 2 | 打开浏览器开发者工具 → Network 面板，通过 API 直接发送 `POST /api/v1/lecs-hosts/{id}/stop` 请求 | 后端拒绝该请求，返回 `403 Forbidden` 或 `409 Conflict` 错误码，表示该主机正在过渡态中不可操作 |
| 3 | 通过 API 直接发送 `POST /api/v1/lecs-hosts/{id}/start` 请求 | 后端同样拒绝该请求，返回 `403 Forbidden` 或 `409 Conflict` 错误码 |
| 4 | 等待主机过渡到"已关机"终态 | 前端按钮状态恢复正常（启动按钮可点击），确认过渡态期间所有操作均被有效阻止 |

### TC-API-040: 验证 POST /api/v1/lecs-hosts/{id}/stop 关机接口

- **优先级**: P1
- **追溯**: SC-04/TC-API-040

| 项目 | 验证内容 |
|------|----------|
| 请求路径 | `POST /api/v1/lecs-hosts/{host_id}/stop`，其中 `{host_id}` 为有效的主机 ID 路径参数 |
| 正常流程 - 请求 | 使用有效认证凭证，对状态为"正常"（normal）的主机发起请求，请求体为空或仅含必要标识 |
| 正常流程 - 响应 | 返回 `200 Accepted` 或 `200 OK` 状态码；响应体包含操作接受确认及主机当前状态为"关机中"（shutting_down） |
| 正常流程 - 异步流转 | 响应返回后，后台异步执行关机流程；通过 GET 查询该主机，状态最终从"关机中"过渡为"已关机"（stopped），过渡时间约 10 秒 |
| 错误 - 非正常状态 | 对已处于"已关机"（stopped）、"关机中"（shutting_down）、"启动中"（starting）、"创建失败"（failed）等状态的主机发送请求，返回 `403 Forbidden` 错误 |
| 错误 - 无认证 | 不带认证凭证发送请求，返回 `401 Unauthorized` 错误 |
| 错误 - 越权访问 | 普通用户尝试关机其他用户的主机，返回 `403 Forbidden` 错误 |
| 错误 - 不存在的主机 | 对不存在的主机 ID 发送请求，返回 `404 Not Found` 错误 |

### TC-API-041: 验证 POST /api/v1/lecs-hosts/{id}/start 启动接口

- **优先级**: P1
- **追溯**: SC-04/TC-API-041

| 项目 | 验证内容 |
|------|----------|
| 请求路径 | `POST /api/v1/lecs-hosts/{host_id}/start`，其中 `{host_id}` 为有效的主机 ID 路径参数 |
| 正常流程 - 已关机状态 | 使用有效认证凭证，对状态为"已关机"（stopped）的主机发起请求 |
| 正常流程 - 启动中响应 | 返回 `200 Accepted` 或 `200 OK` 状态码；响应体包含操作接受确认及主机当前状态为"启动中"（starting） |
| 正常流程 - 已关机异步流转 | 响应返回后，后台异步执行启动流程；通过 GET 查询该主机，状态最终从"启动中"过渡为"正常"（normal），过渡时间约 10 秒 |
| 正常流程 - 创建失败状态 | 对状态为"创建失败"（failed）的主机发起请求，同样返回接受响应并进入"启动中"异步流转 |
| 正常流程 - 创建失败异步流转 | 状态从"启动中"过渡为"正常"，过渡时间约 10 秒 |
| 错误 - 不允许的状态 | 对已处于"正常"（normal）、"启动中"（starting）、"关机中"（shutting_down）等状态的主机发送请求，返回 `403 Forbidden` 错误 |
| 错误 - 无认证 | 不带认证凭证发送请求，返回 `401 Unauthorized` 错误 |
| 错误 - 越权访问 | 普通用户尝试启动其他用户的主机，返回 `403 Forbidden` 错误 |
| 错误 - 不存在的主机 | 对不存在的主机 ID 发送请求，返回 `404 Not Found` 错误 |

## 预期结果

- **关机流程**: 正常状态主机点击关机后，按钮立即置灰、状态变为"关机中"、过渡态期间所有操作按钮禁用、约 10 秒后状态变为"已关机"、启动按钮恢复可点击
- **启动流程（已关机）**: 已关机状态主机点击启动后，按钮立即置灰、状态变为"启动中"、过渡态期间所有操作按钮禁用、约 10 秒后状态变为"正常"、关机按钮恢复可点击
- **启动流程（创建失败）**: 创建失败状态主机点击启动后，按钮立即置灰、状态变为"启动中"、过渡态期间所有操作按钮禁用、约 10 秒后状态变为"正常"、关机按钮恢复可点击
- **过渡态防护**: 关机中/启动中状态下，前端按钮全部禁用，后端拒绝任何生命周期操作请求（返回 403 或 409）
- **API 关机接口**: 仅允许"正常"状态主机关机，返回接受响应后异步流转，非正常状态返回 403，无认证返回 401
- **API 启动接口**: 允许"已关机"和"创建失败"状态主机启动，返回接受响应后异步流转至"正常"，非允许状态返回 403，无认证返回 401
- **时序关键**: 所有状态过渡时间约为 10 秒，按钮状态变化与状态标签变化需保持同步

## 通过标准

- 关机、启动操作的完整状态流转符合规范：按钮置灰时机正确、状态标签变化正确、过渡时间约 10 秒
- 过渡态期间所有前端操作按钮保持禁用，后端接口拒绝重复操作请求
- API 接口对允许的状态返回正确响应并触发异步流转，对不允许的状态返回对应错误码
- 所有操作的最终状态与预期一致，无状态残留或异常
