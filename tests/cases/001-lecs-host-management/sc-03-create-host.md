# SC-03: 创建LECS主机完整流程

**优先级**: P1
**质量维度**: 功能适用性、易用性、正确性

## 前置条件

1. 系统已完成初始化
2. 管理员或普通用户账号已创建并成功登录 Lee 云平台控制台
3. 用户已导航至 `/console/lecs-hosts/list`（LECS主机列表页）
4. 用户当前活跃主机数量 < 100 台（未达配额上限，EC-001 除外）
5. 实例规格数据与操作系统镜像数据可正常获取
6. 浏览器已打开，屏幕分辨率 1280px 及以上

### TC-030: 验证创建后异步状态流转 [P1 | 追溯: spec.md US3-TC-030]

| 步骤 | 操作 | 预期结果 |
|------|------|----------|
| 1 | 创建请求提交成功后，观察列表页自动刷新 | 新创建的主机出现在列表中，状态显示为"创建中"（彩色标签为蓝色），该行操作列全部按钮置灰 |
| 2 | 等待约 30 秒，期间观察列表更新行为 | 主机状态最终变为"正常"（绿色标签）或"创建失败"（红色标签）；当状态变为终态后，操作按钮恢复正常可用性 |
| 3 | 通过浏览器开发者工具 Network 面板观察请求 | 存在"创建中"状态时，列表每约 3 秒自动发起一次轮询请求（GET /api/v1/lecs-hosts 或等价接口）；所有主机进入终态后停止轮询，不再发起额外请求 |

### TC-API-020: 验证 POST /api/v1/lecs-hosts 创建接口 [P1 | 追溯: spec.md US3-TC-API-020]

| 步骤 | 操作 | 预期结果 |
|------|------|----------|
| 1 | 使用 HTTP 客户端（如 curl 或 Postman）发送 POST 请求至 `/api/v1/lecs-hosts`，请求体包含所有必需字段（计费模式、主机名、访问凭据、实例类型、规格、操作系统镜像、IP配置、购买时长），并携带有效认证 Cookie/Token | 请求体格式示例：`{ "billing_mode": "package", "hostname": "valid01", "username": "admin_01", "password": "Admin@123", "instance_type": "economy", "spec": "eco-2c2g", "os": "hwei_euler", "ip_config": {"method": "dhcp"}, "duration": 3 }` |
| 2 | 检查响应状态码 | 返回 HTTP 200 或 201 |
| 3 | 检查响应体 | 返回新主机信息（含 ID、名称、计费模式、IP地址、状态"创建中"等），后台异步执行创建任务 |
| 4 | 构造参数不合法的请求（如主机名 `_invalid`、密码 `Ab1`），发送 POST 请求 | 返回 HTTP 400，响应体包含字段级错误信息（如 `{"success": false, "errors": {"hostname": "主机名格式不合法", "password": "密码长度不足"}}`） |
| 5 | 发送请求但用户当前活跃主机数已达 100 台配额上限 | 返回 HTTP 403，响应体包含配额超限错误信息 |
| 6 | 不携带认证凭证（Cookie/Token）发送 POST 请求 | 返回 HTTP 401 未授权错误 |

## 预期结果

- 创建表单六大配置板块（基础配置、实例规格、操作系统、IP配置、购买时长、配置费用）均正常渲染且可交互
- 表单字段校验（主机名正则 `^[a-zA-Z0-9]{4,10}$`、用户名正则 `^[a-zA-Z0-9_@.+-]{4,16}$`、密码正则 `^[a-zA-Z0-9_@#$%^&+=!-]{8,32}$`）在前端即时生效
- 计费模式默认"包年/包月"，IP配置支持 DHCP/手工两种模式切换
- 操作系统镜像默认"Huawei Euler OS"，可选 Huawei Euler OS/Ubuntu/Windows
- 购买时长可选 1-9个月、1年、2年
- 费用估算值随规格和计费模式变更实时更新
- 确认对话框展示完整配置摘要，取消保留表单，确认提交后重定向至列表
- 新主机初始状态为"创建中"，约30秒后流转至"正常"或"创建失败"终态
- 终态前列表每3秒自动轮询，终态后停止轮询
- 配额上限（100台）时创建请求被拦截并提示"主机数量达到上限"
- API 接口对参数不合法返回400、配额超限返回403、无认证返回401

## 通过标准

- 所有手动测试用例的每一步预期结果均满足
- 表单校验逻辑与 spec.md 定义的正则表达式和长度约束一致
- 费用计算数值精确，无舍入误差导致的金额差异错误（允许 ±0.01 元精度误差）
- 异步状态流转在 60 秒超时阈值内完成，超时降级为"创建失败"
- 配额拦截在前端和后端双层级有效
- API 响应格式与 TC-API-020 定义的 JSON 结构一致
- 页面无 JavaScript 控制台错误
- 所有操作无障碍物（按钮可点击、输入框可聚焦、错误提示可见）
