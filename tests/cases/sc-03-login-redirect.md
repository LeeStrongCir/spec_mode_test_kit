# SC-03: 登录成功后页面跳转

**优先级**: P0
**质量维度**: 功能适用性、易用性

## 前置条件

1. 用户处于登录页面（URL 为 `/login` 或等价路径）
2. 用户已输入有效凭证（`admin/admin@123`）
3. 认证服务运行正常

## 操作步骤

### 步骤 1: 提交登录凭证
1. 在登录页面输入用户名 `admin`
2. 输入密码 `admin@123`
3. 点击"登录"按钮
4. **预期**: 认证请求发送至认证服务端点

### 步骤 2: 等待认证成功响应
1. 接收认证成功响应（HTTP 200）
2. **预期**: 认证 Token 保存至客户端（Cookie / LocalStorage / 内存）
3. **预期**: 路由守卫检测到认证状态变更

### 步骤 3: 验证路由跳转
1. 检查浏览器地址栏 URL 是否变更为 `/console`（或等价控制台路径）
2. **预期**: URL 变为控制台路径
3. **预期**: 页面内容从登录页面切换为控制台页面

### 步骤 4: 验证页面内容切换
1. 检查页面渲染内容
2. **预期**: 页面不再显示登录表单
3. **预期**: 页面显示控制台页面结构（TopBar、概览面板等）

## 预期结果

- 认证成功 → Token 保存 → 路由守卫放行 → 页面跳转至控制台
- URL 从 `/login` 变为 `/console`

## 通过标准

- 登录后 URL 变为控制台路径
- 页面内容渲染为控制台页面
- 不出现 404 或路由错误页面

## 质量维度映射

- **功能适用性**: 路由跳转逻辑正确
- **易用性**: 跳转流畅，用户感知不到延迟
