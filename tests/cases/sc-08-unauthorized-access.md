# SC-08: 控制台页未登录直接访问拦截

**优先级**: P1
**质量维度**: 功能适用性、安全性

## 前置条件

1. 用户处于未登录状态（无有效认证 Token / Session）
2. 用户知道控制台页面 URL（如 `http://localhost:3000/console`）

## 操作步骤

### 步骤 1: 直接访问控制台 URL
1. 在浏览器地址栏输入控制台页面 URL（如 `http://localhost:3000/console`）
2. 按回车键导航
3. **预期**: 路由守卫检测到未登录状态
4. **预期**: 页面重定向至登录页面

### 步骤 2: 验证重定向结果
1. 检查浏览器地址栏 URL
2. **预期**: URL 变为登录页面地址（如 `/login?redirect=/console`）
3. 检查页面内容
4. **预期**: 页面显示登录表单，非控制台页面内容

### 步骤 3: 验证无敏感信息泄露
1. 在登录页面按 F12 打开开发者工具
2. **预期**: 无控制台页面相关的 API 请求被执行
3. **预期**: 无控制台页面数据泄露

## 预期结果

- 未登录用户无法直接访问控制台页面
- 强制重定向至登录页面
- 不泄露控制台页面任何数据

## 通过标准

- 未登录状态下直接请求 `/console` 被重定向至 `/login`
- 重定向后的页面为登录页面而非其他内容
- 无控制台页面数据请求发生

## 质量维度映射

- **功能适用性**: 路由守卫拦截逻辑正确
- **安全性**: 未授权访问被正确阻止，无数据泄露
