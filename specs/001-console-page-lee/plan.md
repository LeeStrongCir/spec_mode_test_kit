# 测试计划: 控制台页面创建与品牌替换

**输入**: 功能测试规格文件 `/specs/001-console-page-lee/spec.md`

> **说明**: 本计划是连接"测试规格说明"与"测试任务分解"的桥梁，定义测试策略、环境、范围、进度和风险。

## 计划摘要

**被测功能概述**: 本次测试覆盖 4 个核心功能：① 创建控制台页面，参照设计稿 `screanshots/华为云控制台.png` 的内容与结构；② 设置管理员初始账号密码 `admin/admin@123`；③ 登录认证成功后自动跳转至控制台页面；④ 全系统"华为云"品牌文案统一替换为"Lee云"。

**测试策略**: 功能测试为主，采用 E2E 自动化测试验证端到端用户旅程（登录→跳转→控制台渲染→品牌验证），辅以人工验证品牌文案的全量替换完整性。P0 场景优先执行，P1/P2 场景按依赖顺序依次覆盖。

**核心测试范围**:
- 登录认证成功后的路由跳转逻辑
- 控制台页面 UI 组件存在性与基本可操作性
- 管理员初始凭证认证流程
- 全系统品牌文案"华为云"→"Lee云"替换完整性
- 未登录状态下的路由守卫拦截
- 错误凭证/空输入的容错处理

**被测系统/服务**: Lee云 云平台管理系统（前端控制台 + 后端认证服务）  
**被测特性**: 控制台页面创建与品牌替换  
**测试类型**: 功能测试

**测试覆盖率目标**: P0 用例 100% 执行通过；P1 用例 ≥90% 执行；全量场景覆盖 SC-01~SC-10

**规模/范围**: 1 个控制台页面 + 1 个登录页面 + 路由守卫模块 + 品牌配置模块
